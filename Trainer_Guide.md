# Module 05 — Trainer Guide (Revised Case-Based Delivery)

## Session identity
- **Module:** 05 — MY BRAND
- **Formal AI Tools session:** CV Building with AI Tools: ChatGPT, Grammarly & Canva
- **Primary output:** Complete ATS-compatible CV, Grammarly-checked and Canva-formatted
- **Official activity:** CV Sprint
- **Source workflow:** ChatGPT → Grammarly → Canva
- **Source peer review:** Ten-item checklist

## Teaching purpose
Participants learn to organise truthful information into a clear CV, use AI to draft selected sections, review language critically, and apply a readable layout. AI must not invent facts, qualifications, work history, language levels, achievements or metrics.

## The continuous case: Maryam Ahmed
Introduce the fictional case immediately after the cover. Do not wait until the middle of the lesson. Every later explanation and demonstration must use the same facts:

| Field | Case fact |
|---|---|
| Profile | Recent Commerce graduate; no formal employment |
| Target | Entry-level Operations role |
| Project | University project: organised sales records using Excel and prepared a summary table |
| Skills | Basic Microsoft Excel; data organisation; summary-table preparation |
| Languages | Arabic — Native; English — A2 |
| Unknown | Professional email, phone, city, institution, graduation year, completed certifications |

Unknown facts must remain placeholders or be omitted. Do not invent a university, graduation date, employer, metrics, contact information or certificate.

## Core teaching loop
For every CV section, follow the same sequence:
1. Explain the purpose of the section and the information it should contain.
2. Point to the matching fact in Maryam's case file.
3. Demonstrate the writing decision or prompt.
4. Show the finished section exactly as it would appear in a CV.
5. Ask learners to identify which facts support each line and which details are still missing.

The presentation includes immediate output slides for Header, Professional Summary, Education, Project Experience, Skills, Languages and Certifications, followed by a complete text CV and a Canva-formatted preview.

## ATS foundation
Explain ATS as Applicant Tracking System: software used by employers to collect and organise applications and make candidate information easier to review or search. Avoid universal claims about how all systems parse, rank or reject CVs. Different systems and employer settings vary.

Teach the practical principle: use clear section headings, relevant evidence and readable text. Do not promise that a specific Canva template or layout guarantees acceptance.

## CV structure
Preserve the seven source fields:
1. Header.
2. Summary.
3. Education.
4. Experience.
5. Skills.
6. Languages.
7. Certifications.

For fresh graduates, a university project can be presented under Project Experience, but must not be described as paid employment.

## ChatGPT summary demonstration
Preserve the source prompt verbatim:

```text
Write a 3-sentence CV summary for a fresh graduate in [field] with skills in [X, Y, Z] targeting [sector].
```

For Maryam, the filled prompt is a trainer demonstration based on the source prompt:

```text
Write a 3-sentence CV summary for a fresh graduate in Commerce with skills in basic Microsoft Excel and data organisation targeting entry-level operations roles.
```

The sample output must contain exactly three sentences. Check that every statement is supported by the case facts. Ask learners to improve the wording without changing the facts.

## Section outputs — model answers

### Header
```text
Maryam Ahmed
[Professional Email] | [Phone Number] | [City, Country]
[LinkedIn URL — optional, if available]
```
The name is fictional. Contact details and profile link are unknown placeholders.

### Professional Summary
```text
Recent Commerce graduate with basic Microsoft Excel skills. Organised sales records and prepared a summary table as part of a university project. Interested in an entry-level operations role.
```
Exactly three sentences. It does not claim formal employment or advanced Excel skills.

### Education
```text
Commerce Graduate
[University / Institution] | [Graduation Year]
```
Only the qualification description is known. Institution and year remain placeholders.

### Project Experience
```text
University Project — Sales Records Organisation
- Organised project sales records using basic Microsoft Excel.
- Prepared a summary table for academic review.
```
Label it as an academic project, not employment. No metrics are invented.

### Skills
```text
Basic Microsoft Excel
Data Organisation
Summary Table Preparation
```
Each item is supported by the project description.

### Languages
```text
Arabic — Native
English — A2
```
Do not upgrade A2 to Fluent or Advanced.

### Certifications
No completed certification is provided in the case. Do not add a certificate. Omit the section until the learner can verify a completed credential.

## Five prompt cards and source ambiguity
The source specifies five prompts and seven CV fields but does not define the grouping. The deck preserves the source Summary prompt verbatim and labels four additional prompt templates as trainer-designed. Do not present the proposed grouping as an official source decision without programme-owner approval.

## Grammarly
Use Grammarly to review spelling/grammar, formality and clarity. Review suggestions rather than accepting them automatically. Tool features may vary by account, plan, browser and text field. If unavailable, use the manual language checklist.

## Canva and final export
Choose a simple template that is currently available. Keep familiar section headings, readable font size and contrast, consistent spacing, limited decoration and selectable text. “ATS-friendly” is not a guarantee. Follow the employer's required file format. Open the exported file and check text order, links, dates and section labels.

## CV Sprint — official activity
Each participant builds their own complete CV using ChatGPT → Grammarly → Canva. The trainer circulates for coaching. Peer review uses the exact ten source criteria: header, summary, experience, education, skills, formatting, ATS keywords, language, length and visual clarity.

## Privacy and accuracy
- Use fictional or anonymised information during demonstrations.
- Do not enter passwords, national ID numbers, financial data, private addresses or confidential employer/client information into AI tools.
- Ask the AI to request missing information instead of guessing.
- Check every claim against the learner's evidence.
- A project, internship or volunteering experience can be represented accurately; do not encourage inventing paid employment.

# Module 05 — Activity Brief
## Official activity: CV Sprint

**Primary output:** Each participant builds a complete CV using the AI-assisted workflow ChatGPT → Grammarly → Canva.

## Part A — Trainer demonstration: one continuous case
The trainer demonstrates the full process using the fictional Maryam Ahmed case. The purpose is to show how each section is created from facts, not to provide students with a CV to copy as their own.

- Recent Commerce graduate; no formal employment.
- Target: entry-level Operations role.
- University project: organised sales records using basic Excel and prepared a summary table.
- Skills: Basic Microsoft Excel; Data Organisation; Summary Table Preparation.
- Languages: Arabic — Native; English — A2.
- Unknown fields: email, phone, city, institution, graduation year, certifications.

After explaining each section, the trainer shows the exact output in CV form. Unknown fields remain placeholders. No employer, dates, achievements, metrics or certifications are invented.

## Part B — Individual CV Sprint
1. Gather accurate information for your own CV.
2. Identify your target role or sector.
3. Use the source ChatGPT prompt to draft a three-sentence Professional Summary.
4. Organise Education and real Experience / Projects accurately.
5. Add only skills and language levels you can demonstrate.
6. Include completed certifications only.
7. Review spelling, formality and clarity with Grammarly or the manual checklist.
8. Format the CV in Canva using a readable, simple template.
9. Export and inspect the actual exported file.
10. Receive peer review using the source ten-item checklist.

## Required evidence
- A complete CV draft with no unsupported claims.
- A saved copy of the source Summary prompt and final three-sentence summary.
- Evidence that each listed skill is real.
- A readable exported file checked after export.
- Completed peer-review checklist and one revision made from feedback.

## Peer review — exact source criteria
1. Header
2. Summary
3. Experience
4. Education
5. Skills
6. Formatting
7. ATS keywords
8. Language
9. Length
10. Visual clarity

## Assessment focus
Review factual accuracy, relevance to the target role, clarity, readable formatting and whether every claim can be explained by the learner. Do not grade students on invented metrics or on a promise of ATS acceptance.

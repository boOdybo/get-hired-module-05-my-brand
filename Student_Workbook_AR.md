# Module 05 — كراسة المتدرب
## MY BRAND | CV Building with AI Tools

### الفكرة الأساسية
استخدم ChatGPT لتنظيم المسودة، وGrammarly لمراجعة اللغة، وCanva للتنسيق. لا تسمح لأي أداة باختراع معلومة عنك. أنت المسؤول عن دقة السيرة الذاتية.

---

## 0. المثال المستمر: مريم أحمد (حالة افتراضية)
سنستخدم حالة واحدة طوال الشرح، ثم تبني سيرتك أنت من بياناتك الحقيقية.

| العنصر | بيانات الحالة |
|---|---|
| التخصص | Commerce Graduate |
| الوظيفة المستهدفة | Entry-level Operations |
| الخبرة | لا توجد وظيفة رسمية؛ يوجد مشروع جامعي |
| المشروع | تنظيم سجلات مبيعات باستخدام Excel وإعداد جدول ملخص |
| المهارات | Basic Microsoft Excel · Data Organisation · Summary Table Preparation |
| اللغات | Arabic — Native · English — A2 |
| بيانات غير متاحة | البريد، الهاتف، المدينة، الجامعة، سنة التخرج، الشهادات المكتملة |

**قاعدة:** بعد شرح كل قسم، راجع مخرج مريم في العرض. الحقول غير المتاحة تبقى بين أقواس مربعة أو تُحذف. لا تنسخ المثال على أنه بياناتك.

### مخرجات الحالة — CV sections

**Header**
```text
Maryam Ahmed
[Professional Email] | [Phone Number] | [City, Country]
[LinkedIn URL — optional, if available]
```

**Professional Summary**
```text
Recent Commerce graduate with basic Microsoft Excel skills. Organised sales records and prepared a summary table as part of a university project. Interested in an entry-level operations role.
```

**Education**
```text
Commerce Graduate
[University / Institution] | [Graduation Year]
```

**Project Experience**
```text
University Project — Sales Records Organisation
- Organised project sales records using basic Microsoft Excel.
- Prepared a summary table for academic review.
```

**Skills**
```text
Basic Microsoft Excel
Data Organisation
Summary Table Preparation
```

**Languages**
```text
Arabic — Native
English — A2
```

**Certifications**
لا تُدرج شهادة؛ لا توجد شهادة مكتملة موثقة في هذه الحالة.

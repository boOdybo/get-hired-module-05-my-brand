# Module 05 — CV Prompt Cards (Trainer Draft)

**Source boundary:** The source provides the exact three-sentence Summary prompt and specifies five prompts, but it does not define how five prompts map to seven CV sections. Only Card 01 is source-verbatim. Cards 02–05 are trainer-designed and provisional.

## Card 01 — Professional Summary (source-verbatim)
```text
Write a 3-sentence CV summary for a fresh graduate in [field] with skills in [X, Y, Z] targeting [sector].
```

## Card 02 — Experience / Projects (trainer-designed)
```text
Turn these real tasks into 3 concise CV bullet points for a [target role]. Use action verbs, name tools only if I used them, and describe outcomes only when supported by my notes. My notes: [paste factual notes]. Do not invent employers, dates, metrics or achievements.
```

## Card 03 — Education (trainer-designed)
```text
Format my education details for a CV using standard headings. Degree: [exact degree]. Institution: [institution]. Dates: [dates]. Relevant coursework or project: [details]. Do not invent grades, awards or graduation dates.
```

## Card 04 — Skills / Languages (trainer-designed)
```text
Organise my verified skills and language levels into clear CV sections for a [target role]. Skills I can demonstrate: [skills]. Tools I have used: [tools]. Languages and honest proficiency levels: [levels]. Do not upgrade my skill or language level.
```

## Card 05 — Certifications / Job Alignment (trainer-designed)
```text
Format these completed certifications for my CV: [certificate, provider, completion date]. Then compare my verified CV content with this job description: [paste job description]. List relevant keywords only when my evidence supports them. Do not invent qualifications or experience.
```

## Demonstration values — fictional Maryam case
- Field: Commerce
- Skills: Basic Microsoft Excel; Data Organisation
- Target: Entry-level Operations
- Evidence: University project — organised sales records and prepared a summary table

Do not use the fictional case as a student's personal information. Replace all fields with verified facts before using a prompt for a real CV.

## 2. The continuous fictional case — enrichment, not source requirement
The revised deck introduces Maryam Ahmed immediately after the cover and carries the same facts through all sections:
- Recent Commerce graduate; no formal employment.
- Target: entry-level Operations role.
- University project: organised sales records using basic Excel and prepared a summary table.
- Skills: Basic Microsoft Excel, Data Organisation, Summary Table Preparation.
- Languages: Arabic — Native; English — A2.
- Unknown details: contact information, institution, graduation year and completed certifications.

The case is trainer-designed enrichment. Unknown fields remain placeholders or are omitted. No university, dates, employer, metrics or certificates are invented.

## 3. Application/output structure
Every CV section follows the same loop: explain purpose → identify evidence in Maryam's case → demonstrate writing decision → show the completed section in CV form → verify factual support.

The seven immediate output views are Header, Professional Summary, Education, Project Experience, Skills, Languages and Certifications. The Certifications output explicitly demonstrates omission because no completed certificate is supplied. A complete text CV and a Canva-formatted preview then assemble the same facts.
